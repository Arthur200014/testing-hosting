## Создание встреч Яндекс Телемоста через GitHub
Прямой переход к запуску: https://github.com/Arthur200014/testing-hosting/actions/workflows/telemost-create.yml

### Настроить один раз
1. Открой **Settings → Secrets and variables → Actions → New repository secret**:
   https://github.com/Arthur200014/testing-hosting/settings/secrets/actions/new
2. Name: `TELEMOST_TOKEN`.
3. Secret: вставь **новый** OAuth-токен Яндекса с разрешением `telemost-api:conferences.create`.
4. Нажми **Add secret**.

Не добавляй токен в файлы, commit, переменные URL или workflow input. Удаление из репозитория не стирает историю Git.

### Как создать звонок
1. Открой вкладку Actions → «Создать встречу Яндекс Телемост».
2. Нажми **Run workflow** → **Run workflow**.
3. Открой новый запуск, дождись зелёной галочки.
4. Перейди в **Summary**, скопируй появившуюся ссылку `join_url` и отправь собеседнику.

GitHub Actions запускает curl к Яндекс API, используя токен из GitHub Secrets. При HTTP 201 пишет `join_url` в сводку запуска.

**Внимание:** репозиторий публичный, поэтому ссылка на встречу в сводке GitHub Actions может быть видна посторонним. Не используй эту версию для конфиденциальных звонков.

### Почему нельзя создать встречу с сайта одним щелчком?
GitHub Pages — статический хостинг. Он не умеет безопасно хранить OAuth-токен и выполнять серверные запросы по нажатию посетителя. Поэтому при варианте «только GitHub» требуется ручное подтверждение Run workflow. Для полноценной кнопки прямо на сайте позже нужен сервер/API.

## Встроенный тестовый звонок
Кнопка «Начать видеозвонок» — отдельный, независимый WebRTC/PeerJS-режим для двух человек: микрофон, камера, демонстрация экрана, завершение для обоих. Это **не** интерфейс Яндекс Телемоста и токен ему не нужен.

## Проверка API
`bash test-token.sh` — локальная проверка на Mac: скрытый ввод OAuth-токена и HTTP-ответ Яндекса. Скрипт создаёт настоящую встречу.

## Дополнительный серверный код
`server.js` — альтернативный экспериментальный Node.js-обработчик, если позже захочешь настоящую кнопку создания встреч непосредственно с сайта. В текущем GitHub-only варианте не используется.
