# Развёртывание API в Timeweb

Status: IN_PROGRESS

## Цель

Запустить существующий ASP.NET API с приватной PostgreSQL в Timeweb.

## Текущее состояние

- Production-клиенты ещё используют Apps Script, переключения не было.
- Коммит `386bf10` сделал `runtime` финальной стадией Dockerfile.
- Первый образ успешно собран Timeweb; запуск остановился сначала на формате
  JWT, затем на отсутствующей `Database__ConnectionString`.
- Пользователь добавил подключение к приватной БД. Последующий деплой показан
  как неудачный; лог обрывается на COPY без сообщения о причине завершения.
- В логе есть многоминутные задержки между COPY. Причина не подтверждена.

## Принятые решения

- Отделить восстановление зависимостей API от тестов и импортёра.
- Сохранить именованные стадии runtime, importer-runtime и test-runner.
- Секреты вводятся только в Timeweb, не в Git или чат.
- Миграции выполняются отдельно через `--migrate` после настройки доступа.
- `/health/ready` проверяет подключение, но не наличие таблиц.
