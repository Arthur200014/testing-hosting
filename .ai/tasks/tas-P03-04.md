## 7. Ограничения

- GitHub API просмотр кода сам по себе не запускает тесты.
- Не проверяем старые EGA/OGA массово. Для затронутой legacy-страницы текущая задача должна предоставить отдельный исполняемый тест.
- Полная P03-04 и G03 требуют дальнейшей работы по фактическому Next.js и безопасности. Нельзя считать их DONE по одному CI bootstrap.
- Запуски GitHub Actions могут быть недоступны из-за прав, квоты или неполадок. При отсутствии реального PASS оставить `BLOCKED` и рабочую ветку.
