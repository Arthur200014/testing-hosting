# Единый Google Apps Script слой для домашних работ ЕГЭ

Status: COMPLETE

## Цель

Подключить оставшиеся 17 страниц ДЗ `EGA/1`–`EGA/5` и `EGA/11` к общей проверке кода ученика и отправке результатов в Google-таблицу. Задания 6–10 уже были переведены в актуальном `main` и должны сохраниться без повторной переделки. Неподтверждённый ответ на новых 17 страницах не должен считаться сохранением. `EGA/12` и вторая часть исключены по прямому указанию владельца.

## Область работы

- 17 страниц ДЗ в `EGA/1`–`EGA/5` и `EGA/11`.
- Единый модуль `shared/interactive/v1/homework-transport.js` для всех страниц.
- Проверка совместимости со всеми 31 страницами первой части `EGA/1`–`EGA/11`.
- Существующие Google-таблица и Apps Script остаются production-хранилищем.

## Вне области работы

- PostgreSQL, Timeweb, деплой, изменение данных/формул задач и дизайна страниц.
- Страницы тренажёров с `submitTest`, не являющиеся страницами `dz*.html`.
- PostgreSQL и любые production-данные, кроме явно разрешённого тестового ученика Хана.

## Текущее состояние

- По опубликованному XLSX найдены 46 URL ДЗ ЕГЭ в каталоге, локально — 50 страниц.
- Действующий Apps Script отвечает HTTP 200, `schemaVersion: 9`.
- Реальный `submitHomework` работает через POST и подтверждает запись `{ok:true,saved:true}`; `doGet` этой операции не поддерживает.
- В актуальном `main` ID страниц EGA/8–EGA/9 уже приведены к каталогу. У шести
  страниц первой части ID есть в каталоге, но отсутствуют строки назначения.
  Это не исправить одним клиентским транспортом.

## Принятые решения

- Все страницы используют один ESM-модуль `homework-transport.js`; второго
  модуля с сетевой или auth-логикой нет.
- Существующие очереди, payload и интерфейс каждой страницы сохранены.
- Только явное подтверждение Apps Script позволяет убрать результат из очереди; HTTP 200, HTML или пустое тело не являются подтверждением.
- При сбое отправки общий слой показывает предупреждение, а существующие очереди/черновики страниц сохраняются.
- Не подменять ID страницы старыми ID каталога без сверки содержания заданий и назначений.

## Открытые вопросы и риски

- Назначения в таблице относятся к конкретным ученикам; для остальных
  учеников даже формы с существующими назначениями закономерно получат
  ошибку «Не найдено назначение».
- Страницы `submitTest` используют другую схему результатов и в этом этапе не мигрируются.
