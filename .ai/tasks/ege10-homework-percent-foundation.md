# ЕГЭ №10: вводные проценты в первой домашней работе

## Цель

Дополнить существующую первую домашнюю работу №10 базовыми задачами на проценты
по моделям парного рабочего листа, не создавая новую страницу и не меняя
`homeworkId`.

## Реализация

- Изменён только `EGA/10/dz1.html`.
- Сохранён `assignmentId`: `HW-EGE10-PART1-MONTHLY`.
- Перед прежними семью задачами добавлены пять вводных задач:
  последовательное изменение цены, возврат цены, тетради и рюкзак,
  высушивание продукта, одинаковые рост и снижение на `p%`.
- У каждой новой задачи есть подробный разбор, таблица, уравнение, шаги и ответ.
- Старый семиэлементный локальный черновик мигрируется на прежние семь задач;
  новые пять полей остаются пустыми, поэтому ответы ученика не сдвигаются.

- Общий Node test suite — PASS.
- Browser matrix для `EGA/10/dz1.html` — PASS.
- Отдельный Chromium-сценарий: 12 задач, 12 правильных ответов дают 100%,

- Все запросы GAS в браузерных проверках перехвачены; рабочая таблица не менялась.
