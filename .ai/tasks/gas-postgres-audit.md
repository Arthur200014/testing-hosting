# Аудит перехода с Google Apps Script на PostgreSQL

Status: DONE

## Цель

Зафиксировать фактические API-контракты, структуру данных, правила и риски
текущего Google Apps Script и связанной Google Sheets перед проектированием
ASP.NET Core API и PostgreSQL.

## Область работы

- Актуальный пользовательский Apps Script из приложенного файла.
- Структура листов и заголовки доступной Google Sheets без публикации данных учеников.
- Текущие browser/API-контракты в репозитории.
- Карта чтения/записи, авторизации, результатов, ДЗ, пробников, занятий,
  отчётов, кэша и триггеров.
- Предлагаемый порядок безопасного переноса и список блокеров.

## Вне области работы

- Реализация ASP.NET Core, PostgreSQL, Redis или импорта.
- Изменение Apps Script, Google Sheets, Firebase, HTML/CSS/JS или UI.
- Копирование персональных данных, ученических кодов и иных значений строк в Git.

## Текущее состояние

- Apps Script и read-only экспорт 20 вкладок проверены.
- Активная вкладка `gid=504334837` подтверждена как `ДЗ_Назначения`.
- Итоговый аудит сохранён в `docs/architecture/gas-postgres-migration-audit.md`.

## Принятые решения

- Аудит выполняется только на чтение.
- В отчёт попадают названия листов, заголовки, типы и агрегаты, но не значения
  строк, имена учеников, коды или иные персональные сведения.
- Наблюдаемые факты отделяются от предположений и недоступных данных.
- Jev выбрал два исследовательских потока: Apps Script — `gpt-6-luna high`,
  таблица и репозиторные контракты — `gpt-6-luna low`; review —
  `gpt-6-luna medium`.

## Проверка

- Исходное рабочее дерево чистое; `main` совпадал с текущим состоянием репозитория.
- CSV активной вкладки и XLSX всей книги: HTTP 200; 20 вкладок.
- Google Sheets REST metadata: ожидаемо недоступно незарегистрированному caller
  (`403 PERMISSION_DENIED`); GID не перебирались.
- API action matrix сверена с dispatcher; семь GET/JSONP mutations подтверждены.
- PII/secret scan итоговых файлов: значений строк, credentials и source IDs нет.
- Независимый review после исправлений: оба HIGH устранены, новых замечаний нет.

## Открытые вопросы и риски

- Deployment permissions и фактически установленные triggers Apps Script не видны.
- Для production import потребуется зарегистрированная read-only Google identity.
- Статический Apps Script admin credential и browser teacher hash должны быть
  отозваны, а не перенесены в новую auth-систему.
