# Общий пакет runtime для интерактивов

Status: DONE

## Цель

Перенести проверенную общую realtime/data-логику из `EGA/6` в репозиторный пакет `shared/interactive/v1`, пригодный для EGA, OGA и новых интерактивов, без изменения существующих публичных URL и поведения.

## Область работы

- Общий пакет `shared/interactive/v1` с небольшим публичным API.
- Совместимые re-export-файлы по старым путям `EGA/6/shared/v1`.
- Перенос Firebase lifecycle в общий пакет с сохранением старого импорта.
- Актуализация связанных тестов и архитектурной документации.
- Детерминированные, браузерные и двухклиентские realtime-проверки.

## Вне области работы

- Изменение UI, текстов и содержания заданий.
- Изменение публичных URL, Firebase-схемы/транспорта или Google Apps Script.
- Перенос остальных интерактивов на новый публичный путь.
- Миграция авторизации или данных на PostgreSQL.

## Текущее состояние

- Каноническая реализация находится в `shared/interactive/v1`.
- Старые пути `EGA/6/shared/v1/*.js` и `EGA/6/realtime-lifecycle.js`
  являются тонкими re-export-совместимостями.
- Общий пакет не импортирует код из `EGA/` или `OGA/`.

## Принятые решения

- Каноническая реализация будет находиться в `shared/interactive/v1`.
- Старые EGA-пути останутся рабочими через тонкие re-export-совместимости.
- Публичная поверхность останется компактной: `interactive-runtime.js`, `platform-data.js`, `platform-realtime.js`.
- Firebase пока остаётся realtime-транспортом; провайдерная граница сохраняется.
- Jev выбрал: реализация `gpt-5.6-sol` high, тестирование и review `gpt-6-luna` medium.
