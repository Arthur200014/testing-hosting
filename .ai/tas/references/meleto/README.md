# Meleto: пакет референсов

74 снимка страниц и состояний. Съёмка: 13 ноября 2026 года.

1. BUILD_PROMPT_RU.md — готовый запрос для вставки в чат разработчика.
2. screens/ — изображения, ID совпадает с PDF.
3. screen_specs.json — путь открытия, элементы и требования по каждому кадру.
4. index.html — автономный каталог: открой локально в браузере.

PDF: Meleto_Design_Reference_and_Build_Brief.pdf (92 страниц, поставляется отдельно).

Это аудит доступного кабинета преподавателя, а не полный доступ к исходному коду или БД Meleto. Проектная модель в описаниях предложена для собственной реализации. Экран входа, другие роли, активный звонок, платежи и ряд вложенных состояний не сняты; перечень есть в PDF и запросе. Контакты и ссылки приглашений скрыты; изображения досок — примеры учебного контента. Маски не являются частью дизайна.
