# New Chat — TEACHER AI STUDENT

Copy this prompt into a new regular ChatGPT conversation:

```text
Продолжай разработку TEACHER AI STUDENT прямо в GitHub:
Arthur200014/testing-hosting.

Главная цель — рабочий продукт, минимум лишних операций и расхода контекста.

1. Прочитай .ai/tas/HANDOFF.md на main и краткий AGENTS.md.
   Если есть ACTIVE_BRANCH, продолжай её с последнего опубликованного коммита.
   Иначе возьми NEXT_ACTION. Не запускай новую задачу до завершения текущей.
2. Используй .ai/CONTEXT_MAP.md. Смотри только нужные функции, зависимости
   и тесты; не читай целиком EGA/, OGA/, platform/, большие HTML и diff.
3. Если задачи и код достаточно понятны, сразу реализуй. Не делай ради
   формальности план-коммит, Jev, группу агентов или подробную тест-матрицу.
4. Проверяй только изменённое поведение и важные связанные регрессии.
   Существующие тесты используй по месту; новые добавляй при реальном риске.
   Для auth, данных учеников, backend и realtime проверки обязательнее.
   Что не запускалось, честно обозначай NOT_RUN.
5. Сделай commit + push. Для длинной незавершённой задачи используй
   tas/<TASK_ID> и сохраняй checkpoint после значимого этапа.
   Если работа прервётся, оставь краткий NEXT_STEP в HANDOFF.
6. В конце сообщи: что сделано, фактические проверки, ссылка на коммит,
   что осталось. Не останавливайся на одном планировании.

Не меняй несвязанные файлы, публичные адреса и реальные данные учеников.
```

Рабочее правило иерархии: `AGENTS.md` — основная инструкция; этот текст только удобный вход в новый чат.
