# Запрос для нового чата

## Короткий вариант

Скопируй в новый чат с доступом к репозиторию:

`Продолжай по хандоффу в https://github.com/Arthur200014/testing-hosting. Прочитай AGENTS.md и .ai/tas/HANDOFF.md на main, продолжи ACTIVE_BRANCH или NEXT_ACTION по действующему RELEASE_PLAN.md. Для Meleto используй MELETO_REFERENCE.md и нужные скриншоты. Реализуй следующий рабочий сценарий, проверь его, сохрани коммит и обнови HANDOFF. Не удаляй учеников и доски, не меняй пароли и не повторяй импорт.`

## Если нужен полный запрос

`Продолжай TEACHER AI STUDENT в существующем репозитории https://github.com/Arthur200014/testing-hosting. Владелец хочет максимально точно воспроизвести доступный кабинет преподавателя Meleto, начиная с классов; собственные особенности позже. Не начинай проект с нуля и не делай повторную инвентаризацию всего репозитория.

Сначала прочитай AGENTS.md и .ai/tas/HANDOFF.md на main. Если ACTIVE_BRANCH указан, проверь её HEAD и продолжи незавершённую работу с её NEXT_STEP. Иначе реализуй NEXT_ACTION. Очередь — .ai/tas/RELEASE_PLAN.md, приёмка — PHASE_CHECKLISTS.md, навигация — .ai/CONTEXT_MAP.md. Старые Mxx/Pxx файлы исторические и не задают следующую задачу.

Для текущих экранов найди Meleto_Reference_Pack.zip в моей ChatGPT Library по ссылке из .ai/tas/MELETO_REFERENCE.md. Посмотри только PNG/JSON нужных ID из MELETO_SCREEN_INDEX.md. Если доступа к архиву нет, скажи, что нужно прикрепить ZIP; не утверждай совпадение дизайна без кадров. Не путай наблюдаемый интерфейс с проектной схемой БД из PDF.

Реализуй один сквозной сценарий на существующих .NET/PostgreSQL/API и синтетических данных: UI + реальное чтение/сохранение + права + ошибка/отмена + визуальная сверка. Не создавай статические кнопки, которые кажутся работающими. Проверяй соразмерно риску и указывай PASS/FAIL/NOT_RUN. После значимого этапа commit/push и короткий HANDOFF: что готово, ветка/коммит, конкретный следующий шаг. Для долгой задачи используй одну рабочую ветку. Не удаляй учеников/доски, не меняй пароли, не повторяй импорт и не переключай текущий production writer без отдельного явного решения.`

Одной короткой фразы достаточно, если новый чат может читать репозиторий и пакет в Library. Если архив недоступен в этом чате, приложи [Meleto_Reference_Pack.zip](https://chatgpt.com/library?file_id=libfile_2a4feb1037c08191997ce235ce5fd686&account_id=personal).
