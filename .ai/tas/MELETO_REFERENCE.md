Не переносить в UI чёрные маски персональных данных со снимков.

## Границы и проверка

Нет достоверных кадров входа/регистрации/восстановления, полных кабинетов ученика и представителя, активного звонка, оплаты и внутреннего кабинета школы. Пустые состояния не показывают детальный процесс заполнения. Для них фиксировать `NOT_OBSERVED` и отдельное продуктовое решение, не приписывать источнику недоказанное поведение.

Для каждого сценария записывать ID референса, путь открытия, экран/состояние/форму, источник данных, переходы, действие сохранения/отмены и статус `DONE / PARTIAL / NOT_STARTED / NOT_OBSERVED`. Снимать сравнительный скриншот на одинаковом viewport после реализации UI, проверять размеры, вкладки, плотность и формы. Готово означает работу с данными и серверными правами, а не статический макет.
