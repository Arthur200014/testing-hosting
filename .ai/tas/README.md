# TEACHER AI STUDENT — продолжение разработки

**Репозиторий:** `Arthur200014/testing-hosting`. TAS развивается внутри него;
не создавать отдельный проект и не начинать реализацию заново.

## Быстрый старт

1. Прочитать `AGENTS.md` и `.ai/tas/HANDOFF.md` на `main`. Если указан
   `ACTIVE_BRANCH`, продолжить её, иначе брать `NEXT_ACTION`.
2. По `.ai/CONTEXT_MAP.md` найти только связанные файлы, нужные тесты и
   зависимости. Не сканировать целиком `EGA/`, `OGA/`, `platform/`.
3. Проверить актуальный исходный код перед изменением. Карточки задач, подробные
   планы и архитектурный аудит использовать **по необходимости**, а не как
   обязательный подготовительный этап.
4. Сделать рабочее изменение, выполнить соразмерные проверки и commit/push.
   Небольшая завершённая задача может идти сразу в `main`; рисковую или
   незавершённую вести в `tas/<TASK_ID>` с checkpoint после значимого этапа.
5. Кратко обновить `HANDOFF.md`: статус, ветка, коммит, результаты проверок,
   один следующий шаг. Не называть `PASS` то, что реально не запускалось.

Источник правил — **`AGENTS.md`**, затем текущий Git-код. Старые обязательные
«план-коммиты», запуск агентов, длинные тест-матрицы, частые checkpoints и
полные diff **не нужны**. Новые тесты — когда есть реальный риск регрессии.

## Продуктовый приоритет

Учитель задаёт тему → AI собирает проверяемый `LessonDefinition` из
разрешённых материалов → ученик проходит интерактивный урок → ответы и ДЗ
сохраняются → модель знаний рекомендует следующий ресурс.

Существующие `platform/` и `shared/interactive/v1/` повторно не создавать.
Рабочие страницы, Google Apps Script/Firebase, production-трафик, реальные
данные учеников и публичные URL не менять без отдельной задачи и проверки.

## Проверки

`.github/workflows/tas-task-ci.yml` выбирает тесты по изменённым модулям.
Backend проверяется на изолированном PostgreSQL; отдельный воспроизводимый
smoke запуска — `bash platform/scripts/backend-smoke.sh`. Конкретные
успешные CI-запуски и ограничения фиксируются в `HANDOFF.md`.
Зелёный CI не подтверждает автоматически production-развёртывание.
