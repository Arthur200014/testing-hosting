# testing-hosting

Рабочий репозиторий учебных интерактивов и развиваемой платформы **TEACHER AI STUDENT (TAS)**.

## Где что находится

- `EGA/`, `OGA/` — действующие страницы ЕГЭ и ОГЭ. Не переделывать без отдельной задачи.
- `shared/interactive/v1/` — общие интерактивные и realtime-компоненты.
- `platform/` — существующий ASP.NET Core backend и тесты; он ещё не заменил все legacy-интеграции.
- `compose.yaml` — локальная инфраструктура PostgreSQL/API.
- `docs/architecture/` — подтверждённые архитектурные решения и миграция.
- `.ai/START_HERE.md`, `AGENTS.md` — правила работы ИИ со scoped-контекстом.
- **`.ai/tas/README.md` — ТЗ, чеклисты, доска задач и передача контекста между чатами.**

## Как продолжать разработку TAS

Прочитай `.ai/tas/NEW_CHAT_PROMPT.md` и `.ai/tas/HANDOFF.md`.
Искать код по `.ai/CONTEXT_MAP.md`, а не сканировать весь репозиторий.
После одной проверенной задачи сохранить её состояние и автоматически сделать коммит в `main` по `AGENTS.md`.

Не копируй секреты и ученические данные в Git. Текущая версия кода в `main` важнее старых планов.
