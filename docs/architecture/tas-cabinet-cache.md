# Запуск кабинетов и кэш TAS

При загрузке преподаватель и ученик видят нейтральный экран, пока тот же сервер проверяет cookie. Действующая сессия открывает кабинет. Ответ об отсутствии сессии открывает форму входа. При сетевой ошибке экран предлагает повторить проверку. Преподаватель возвращается в сохранённый раздел, класс или занятие после проверки доступа. В sessionStorage сохраняется только позиция внутри кабинета.

PostgreSQL хранит сессии, роли, классы, задания и доски. API проверяет права до обращения к кэшу. Отзыв доступа действует через обычную проверку PostgreSQL.

Redis хранит результаты повторяющихся чтений справочников. Первый подключённый справочник — список активных программ преподавателя. Ключ включает идентификатор рабочей области и версию формата. Запись живёт 30 секунд. При недоступности Redis запрос читает PostgreSQL. Схема и формат API сохраняются. Добавление новых справочников требует явной стратегии инвалидирования при записи.

Для подключения существующего Redis передайте `Redis__ConnectionString` через секреты среды приложения. Используйте приватный адрес и TLS, если его предоставляет хостинг. Без настройки API читает PostgreSQL напрямую. В CI профиль `test` поднимает изолированный Redis и проверяет попадание в кэш, чтение после удаления записи и изоляцию рабочих областей.
