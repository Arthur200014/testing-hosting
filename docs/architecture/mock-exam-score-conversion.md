# Перевод баллов пробников

## Ученический интерфейс

Общая логика находится в
`shared/interactive/v1/mock-score-conversion.js` и используется мостом
`mock-exam-persistence.js` для обеих форм.

- ЕГЭ: первичный балл переводится в тестовый балл из 100.
- ОГЭ: первичный балл переводится в отметку 2–5 по порогам
  `0–7 → 2`, `8–14 → 3`, `15–21 → 4`, `22–31 → 5`.
- Сразу после отправки первой части значение показывается как предварительное.
- После проверки второй части значение из строки листа `Пробники` считается
  итоговым и заменяет предварительное на экране ученика.

Форма отправляет перевод вместе с исходными полями, не заменяя их:

- ЕГЭ: `primaryScore`, `maxPrimaryScore`, `scorePercent`, `testScore`;
- ОГЭ: `primaryScore`, `maxPrimaryScore`, `scorePercent`, `gradeMark`.

## Лист «Пробники»

Используются существующие колонки без создания нового листа:

| Колонка | Поле | Назначение |
|---|---|---|
| F | `score` / `testScore` | тестовый балл ЕГЭ |
| G | `primaryScore` | первичный балл |
| L | `gradeMark` | отметка ОГЭ |
| M | `maxPrimaryScore` | максимум первичных баллов текущего этапа |
| N | `scorePercent` | процент выполнения |

Поиск ранее сданного пробника читает `A,B,C,K,F,G,L,M,N`. Поэтому результат
доступен и на другом устройстве, а после проверки учителем форма получает
обновлённые итоговые значения из той же строки.

## Apps Script

Полный обновлённый исходник для развёртывания сохранён в приложенном к задаче
файле `Вставленный текст.txt`. Сервер выполняет перевод повторно, чтобы старый
или закэшированный клиент не мог оставить колонки F/L пустыми, и при
`finalizeMockReview` атомарно обновляет в одной строке:

- ЕГЭ: `score`, `primaryScore`, `maxPrimaryScore`, `scorePercent`;
- ОГЭ: `gradeMark`, `primaryScore`, `maxPrimaryScore`, `scorePercent`.

Клиентский код и тесты можно опубликовать через GitHub Pages обычным push.
Изменения Apps Script начинают работать на сервере только после сохранения и
нового развёртывания приложенного скрипта в Google Apps Script.

## Регрессии

- `node --test shared/interactive/v1/mock-score-conversion.test.mjs`
- `node --test shared/interactive/v1/mock-exam-persistence.test.mjs`
- `node scripts/ege-mock-browser-matrix.mjs`
- `node scripts/oge-mock-browser-matrix.mjs`

Браузерные матрицы перехватывают GAS и не записывают тестовые результаты в
рабочую таблицу.
