# Architecture memory

Architecture documents preserve stable, verified decisions beyond one
implementation task. They describe current boundaries and invariants, not daily
progress. Task-specific history belongs in `.ai/tasks/`.

Possible future topics include realtime, data storage, interactive core, and
authentication. Create a topic file from `_TEMPLATE.md` only when current code
and accepted decisions provide enough evidence to describe it accurately. Keep
the document concise and revisit its facts when the code changes.
