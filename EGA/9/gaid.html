Алгоритм «ОТВЕТ»

Пять шагов по буквам слова ОТВЕТ — читай сверху вниз, каждая буква это шаг.

О
Определи

Выпиши формулу. Отметь, что ДАНО и что нужно НАЙТИ.

Т
Тип формулы

Посмотри, где стоит неизвестная — это сразу задаёт метод (см. таблицу ниже).

В
Вычисли

Подставь числа и реши уравнение выбранным методом.

Е
Если «не менее / наибольшее»

Это неравенство: реши как уравнение, найди корни, по эскизу параболы выбери границу. Тут теряют балл чаще всего.

Т
Точно проверь

Единицы (км→м) · нужный корень (t>0) · та ли граница. Запиши одно число без единиц.

Степени

Основание a > 0. Все правила работают в обе стороны — и «свернуть», и «развернуть».

aᵐ · aⁿ = am+n aᵐ : aⁿ = am−n (aᵐ)ⁿ = am·n (a·b)ⁿ = aⁿ·bⁿ (a/b)ⁿ = aⁿ/bⁿ a⁰ = 1 a⁻ⁿ = 1/aⁿ (a/b)⁻ⁿ = (b/a)ⁿ

🔟 Степени десятки — нужны почти всюду

10ᵃ · 10ᵇ = 10a+b  ·  10ᵃ : 10ᵇ = 10a−b  ·  (10ᵃ)ᵇ = 10ab

Число вида c·10ᵃ делим отдельно: числа на числа, степени на степени.

№ 05

T⁴ = P/(σS) = 4,104·10²⁷ / (5,7·10⁻⁸ · (1/18)·10²¹).

Знаменатель: 5,7/18 = 0,31(6); 10⁻⁸·10²¹ = 10¹³.

Итого T⁴ = 1296·10¹² ⟶ T = 6000.

√

Корни и дробные степени

a1/n = ⁿ√a am/n = ⁿ√(aᵐ) √(a·b) = √a·√b √(a/b) = √a/√b (√a)² = a (a ≥ 0) √(a²) = |a| — не просто a!

Как решать xⁿ = b

• n нечётное: ровно один корень x = ⁿ√b (знак любой).
• n чётное, b > 0: два корня x = ±ⁿ√b — по смыслу берут нужный.
• n чётное, b < 0: корней нет.

Выразить основание из степени: из Vᵏ = c возведи обе части в степень 1/k ⟶ V = c1/k
№ 04

p·V5/3 = 6,4·10⁶, p = 2·10⁵ ⟶ V5/3 = 32 ⟶ V = 323/5 = (2⁵)3/5 = 2³ = 8.

№ 03

l = √(2Rh) ⟶ h = l²/(2R). h₁ = 16/12800, h₂ = 784/12800.

Разность = 768/12800 = 0,06 км = 60 м.

Показательные уравнения

Неизвестная стоит в показателе. Цель — одинаковые основания слева и справа.

aˣ = aʸ ⇔ x = y aˣ = 1 ⇔ x = 0 aˣ = b ⇔ x = logₐb aˣ > 0 всегда

💾 Что помнить наизусть

21..10 = 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024.
Дроби: 1/2 = 2⁻¹, 1/8 = 2⁻³, 1/32 = 2⁻⁵.
31..5 = 3, 9, 27, 81, 243.   51..4 = 5, 25, 125, 625.

Алгоритм: 1) оставь степень в одной части; 2) второе число представь степенью того же основания; 3) приравняй показатели; 4) реши линейное уравнение.

№ 06

192·2−t/10 = 6 ⟶ 2−t/10 = 6/192 = 1/32 = 2⁻⁵ ⟶ −t/10 = −5 ⟶ t = 50.

Логарифмы

logₐb — это показатель, в который надо возвести a, чтобы получить b. ОДЗ: a > 0, a ≠ 1, b > 0.

logₐb = c ⇔ aᶜ = b logₐ1 = 0 logₐa = 1 logₐ(xy) = logₐx + logₐy logₐ(x/y) = logₐx − logₐy logₐ(xⁿ) = n·logₐx alogₐb = b logₐb = log꜀b / log꜀a lg = log₁₀ · ln = logₑ
Главный приём — снять логарифм: сначала вырази сам логарифм (раздели на коэффициенты), затем перейди к степени: logₐX = c ⟶ X = aᶜ.
№ 07

15960 = 13,3·2·300·log₂(p₂/1,75) ⟶ log₂(p₂/1,75) = 2 ⟶ p₂/1,75 = 2² = 4 ⟶ p₂ = 7.

№ 08

t = aRC·log₂(U₀/U), aRC = 0,8·8·10⁶·6·10⁻⁶ = 38,4.

76,8 = 38,4·log₂(34/U) ⟶ log₂(34/U) = 2 ⟶ 34/U = 4 ⟶ U = 8,5.

Нельзя частые «выдуманные» свойства
✗ log(x+y) ≠ log x + log y
✗ log(x/y) ≠ log x / log y
✗ (log x)² ≠ 2·log x

Квадратные уравнения

a·x² + b·x + c = 0  ·  D = b² − 4ac  ·  x₁,₂ = (−b ± √D)/(2a)

D > 0 — два корня · D = 0 — один (x = −b/2a) · D < 0 — корней нет.

⚡ Быстрые способы

• Виета (при a = 1): x₁ + x₂ = −b, x₁·x₂ = c.
• Нет c: ax² + bx = 0 ⟶ x(ax + b) = 0 ⟶ x = 0 или x = −b/a.
• Нет b: ax² + c = 0 ⟶ x² = −c/a.

№ 09

24t − 1,5t² = 90 ⟶ t² − 16t + 60 = 0 ⟶ t = 6 и t = 10. Торможение длится 24/3 = 8 с ⟶ t = 6.

№ 13

15t + 3t² = 2250 ⟶ t² + 5t − 750 = 0 ⟶ t = 25 и t = −30. Время > 0 ⟶ 25.

Парабола и квадратные неравенства

Схема, которая закрывает все задачи со словами «не менее», «наибольшее», «сколько времени».

вершина: x₀ = −b/(2a)  ·  y₀ = y(x₀)

a > 0 — ветви вверх, в вершине минимум.
a < 0 — ветви вниз, максимум.
Расстояние между корнями: |x₂ − x₁| = √D/|a|.

Как выбрать ответ (a > 0)

• y > 0 → вне корней: x < x₁ или x > x₂.
• y < 0 → между корнями: x₁ < x < x₂.
• При a < 0 всё наоборот.
• «Сколько времени / секунд длится» → это длина интервала: x₂ − x₁.

№ 11

2 + 13t − 5t² ≥ 8 ⟶ 5t² − 13t + 6 ≤ 0 ⟶ корни t = 0,6 и t = 2. Ветви вверх, «≤ 0» → между корнями. Длина = 2 − 0,6 = 1,4.

№ 10

1300 + 98t − (14/3)t² ≤ 1720 ⟶ корни t = 6 и t = 15. «Наибольшее время, пока не испортится» — 6.

№ 12

(1/98)t² − (4/7)t + 8 = 0 ⟶ ×98 ⟶ t² − 56t + 784 = 0 ⟶ D = 0, один корень t = 28 мин.

№ 14

p(65 − 5p) ≥ 150 ⟶ p² − 13p + 30 ≤ 0 ⟶ 3 ≤ p ≤ 10. Наибольшая цена — 10.

➗

Дробно-рациональные

Уравнение

Дробь = 0 ⟺ числитель = 0 и знаменатель ≠ 0.   A/B = C ⟶ умножь на B (B ≠ 0) ⟶ A = BC.

В конце проверь ОДЗ и отбрось корни, где знаменатель обнулился.

Выразить переменную из знаменателя: из U = εR/(R+r) ⟶ U(R+r) = εR ⟶ Ur = R(ε−U) ⟶ R = Ur/(ε−U)

Неравенство

Нельзя просто домножать на знаменатель — его знак неизвестен!

1) перенеси всё в одну часть; 2) общий знаменатель; 3) разложи на множители; 4) метод интервалов: нули числителя (закрашены при ≥) и нули знаменателя (всегда выколоты).

Исключение: если знаменатель по смыслу всегда > 0 (R+r, c+u), домножать можно, знак не меняется.

№ 15

220/R ≤ 2,5 ⟶ R ≥ 88 ⟶ минимальное 88 Ом.

№ 17

65R/(R+0,5) ≥ 60. Знаменатель > 0 ⟶ 65R ≥ 60R + 30 ⟶ 5R ≥ 30 ⟶ R ≥ 6.

№ 18

1500(f−247)/(f+247) ≤ 18 ⟶ 1482f ≤ 374946 ⟶ f ≤ 253.

№ 20

170(c+12)/(c−6) ≥ 180, при c > 6 ⟶ 3120 ≥ 10c ⟶ c ≤ 312.

Подстановка, единицы, слова-маркеры

Порядок действий

скобки → степени и корни → умножение и деление → сложение и вычитание.

Слова-маркеры

«не менее» = ≥«не более» = ≤«превышает» = > «наибольшее/наименьшее» → крайний корень или вершина «отличаются не менее чем на d» → |A−B| ≥ d

Единицы и приставки

1 км = 1000 м1 ч = 3600 с1 т = 1000 кг 1 МГц = 10⁶ Гц1 кВ = 1000 В н = 10⁻⁹мк = 10⁻⁶м = 10⁻³к = 10³М = 10⁶Г = 10⁹
Какой корень оставить: время, масса, объём, длина, сопротивление, частота — всегда > 0, отрицательный корень отбрасывай. «Не менее/не более» — граница включается; «более/менее» — нет.

Ошибки: где теряют балл

✗ как ошибаются — ✓ как правильно. фиолетовый = редкая, коварная ошибка.

A · Единицы и «что именно спрашивают»
A1 Не перевёл единицы
✗ №03: нашёл разность 0,06 (км) и записал «0,06».
✓ Просят в метрах: 0,06 км = 60. Подчёркивай «Ответ в …».
A2 Ответил не на тот вопрос
✗ №03: посчитал конечную высоту, а спрашивали «на сколько подняться».
✓ Это разность h₂ − h₁. Перечитывай вопрос после решения.
A3 Лишние единицы / нули
✗ «60 м», «0,180», «8,50».
✓ В бланк — только 60, 0,18, 8,5. Запятая, а не точка.
A4 Смешанные единицы в формуле коварно
✗ №08: U₀ = 34 кВ, испугался и стал переводить кВ в В.
✓ Под log стоит отношение U₀/U — единицы сокращаются. Ответ в кВ: 8,5.
A5 Потерял множитель приставки коварно
✗ №18: перевёл 247 МГц в 247·10⁶ и получил 253000000.
✓ Частоты в отношении — считай в МГц, ответ 253.
B · Корни, знаки и выбор решения
B1 Взял посторонний корень
✗ №09: t = 6 и 10; записал 10.
✓ Машина остановится в t = v₀/a = 8 с, дальше формула не работает ⟶ t = 6.
B2 Оставил отрицательный корень
✗ №13: 25 и −30; записал −30.
✓ Время > 0 ⟶ 25. То же для массы, объёма, длины.
B3 Знак в дискриминанте / вершине
✗ D = b² + 4ac или x₀ = b/(2a).
✓ D = b² − 4ac, x₀ = −b/(2a). Подставляй a, b, c в скобках.

✗ №16: не проверил d₁ ∈ [15; 40], d₂ ∈ [100; 120].

✗ Сокращает корень с квадратом, теряя знак.

✗ Получил T⁴ = −1296·10¹² и «извлёк» корень.
✓ Такого корня нет — значит, ошибка выше. Вернись и пересчитай.

D · Логарифмы и показательные
D1 Выдумал свойство
✗ log(x+y)=logx+logy, (logx)²=2logx.
✓ Сумма логарифмов = логарифм произведения; n выносится только из степени под log.
D2 Снял логарифм, не выразив
✗ №07: сразу p₂/1,75 = 2¹⁵⁹⁶⁰.
✓ Сначала раздели: log₂(…) = 2, и только потом ⟶ p₂/1,75 = 2².

✗ №06: 2−t/10 = 1/32, а пишет −t/10 = 5 ⟶ t = −50.
✓ 1/32 = 2⁻⁵ ⟶ −t/10 = −5 ⟶ t = 50.

✗ Оставил корень, где аргумент ≤ 0 или основание = 1.
✓ Под логарифмом строго > 0; основание > 0 и ≠ 1.

✗ Нажал «log» (это log₁₀) и получил дробь вместо 2.
✓ log₂x = lgx/lg2. В задании 9 числа «красивые» — ищи степень двойки.
D6 Спутал основание и аргумент
✗ log₂8 = 1/3.
✓ log₂8 = 3, потому что 2³ = 8.
