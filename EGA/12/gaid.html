Алгоритм «ПТИЦА»: пять шагов на любой прототип

Первые буквы шагов складываются в слово. Забыл порядок — вспомни птицу.

🐦 Запомни одно слово

ПТИЦА
П
Прочитай вопросЧто спросили: точку (ответ — x) или значение (ответ — y)? Подчеркни это слово прямо в КИМе. Всё остальное решение зависит от него.
Т
ТерриторияОбласть определения + отрезок. ln x → x > 0, √x → x ≥ 0, дробь → знаменатель ≠ 0. Отрезок из условия — тоже часть территории.
И
Ищи производнуюУпрости → продифференцируй → собери в дробь или вынеси общий множитель. Цель — вид «произведение или дробь», где знак читается по кусочкам.
Ц
Цель под прицелом: y′ = 0Реши уравнение. Корни вне территории — вычеркни. Корней нет вообще — отлично, функция монотонна.
А
Ответь на тот вопрос, который задалиСпросили точку → знаковая прямая (алгоритм ЗНАКИ, страница 3) → пишешь x. Спросили значение → таблица: корни внутри отрезка + оба конца → сравниваешь → пишешь y.

🎯 Та же ПТИЦА в виде блок-схемы

📌 ПТИЦА в деле: полный разбор одной задачи

Задача. Найдите наименьшее значение функции y = 9x − ln(x + 4)⁹ на отрезке [−3,5; 0].

Шаг за шагом
  1. П — спрошено «наименьшее значение» → в ответ пойдёт y, значит подставлять придётся.
  2. Т — под логарифмом x + 4 > 0, то есть x > −4. Отрезок [−3,5; 0] целиком внутри — всё честно.
  3. И — сначала упрощаем: ln(x+4)⁹ = 9·ln(x+4). Тогда y = 9x − 9·ln(x+4) и y′ = 9 − 9/(x+4).
  4. Ц — 9 = 9/(x+4) → x + 4 = 1 → x = −3. Корень внутри отрезка — оставляем.
  5. А — считаем три числа: y(−3,5) = −31,5 − 9·ln 0,5 ≈ −25,3; y(−3) = −27 − 9·ln 1 = −27; y(0) = 0 − 9·ln 4 ≈ −12,5. Наименьшее: −27.
Что здесь было главным. Не производная — её тут на десять секунд. Главным был шаг И: если не свернуть степень логарифма, задача превращается в мучение. И шаг А: без концов отрезка ответ не обоснован.

Теория с примерами: от наклона до сложной функции

Каждое правило — сначала на детском примере, потом на настоящем из ЕГЭ.

🎬 Живая идея: производная — это наклон

Птица летит по графику. Жёлтая палка под ней — касательная. Её наклон и есть значение производной в этой точке.

Жёлтая палка горизонтальна ровно дважды — это и есть точки экстремума.

Вся задача 12 — про это. Производная показывает, растёт функция или падает. Место, где рост сменился падением, — максимум. Где падение сменилось ростом — минимум.

📖 Два слова, из-за которых теряют балл

«Найдите точку минимума»
В ответ идёт x — координата по горизонтали. Значение функции считать не нужно вообще.
«Найдите наименьшее значение»
В ответ идёт y — высота. Подставляем x в функцию и получаем число.

Мнемоника: «тОчка — Отвечаю иксом».

🃏 База: таблица производных

Нажми карточку, чтобы перевернуть. Без этой колоды дальше идти бессмысленно.

Производная константы = 0. Поэтому свободные члены (+43, −97, +365) на ответ не влияют никогда. Не переписывай их вообще.

➕ Правило 1. Сумма и разность — самое лёгкое

(u ± v)′ = u′ ± v′   ·   (k·u)′ = k·u′

Дифференцируем каждое слагаемое отдельно, коэффициент просто выносим.

Простой пример

y = 5x³ − 7x + 2 → y′ = 5·3x² − 7·1 + 0 = 15x² − 7

Пример из ЕГЭ

y = 0,5x² − 21x + 110·ln x + 43

  1. (0,5x²)′ = 0,5·2x = x
  2. (−21x)′ = −21
  3. (110·ln x)′ = 110·(1/x) = 110/x
  4. (43)′ = 0
  5. Итого: y′ = x − 21 + 110/x, а дальше — к общему знаменателю: y′ = (x² − 21x + 110)/x
Зачем приводить к общему знаменателю? Чтобы получить произведение и дробь — вид, в котором знак читается по кусочкам (см. страницу 3). Пока производная — это «сумма всего подряд», знаки определить нельзя.

✖️ Правило 2. Произведение — здесь падают чаще всего

(u·v)′ = u′·v + u·v′

Почему так, а не u′·v′? Представь прямоугольник со сторонами u и v — его площадь и есть произведение. Увеличим x чуть-чуть: обе стороны подрастут. Площадь прибавилась двумя полосками.

Простой пример — проверка формулы

Возьмём y = x² · x³. Мы знаем ответ заранее: y = x⁵, значит y′ = 5x⁴.
По формуле: u = x², u′ = 2x; v = x³, v′ = 3x² →
y′ = 2x·x³ + x²·3x² = 2x⁴ + 3x⁴ = 5x⁴ ✔ сходится.
А если бы работало «u′·v′», получилось бы 2x·3x² = 6x³ — неверно.

Пример из ЕГЭ — экспоненциальный босс

Найдите точку минимума y = (x² − 11x + 11)·ex+13

  1. Обозначаем: u = x² − 11x + 11, v = ex+13.
  2. Считаем: u′ = 2x − 11, v′ = ex+13 (показатель x+13, его производная = 1, поэтому экспонента не меняется).
  3. Подставляем: y′ = (2x − 11)·ex+13 + (x² − 11x + 11)·ex+13
  4. Выносим экспоненту за скобку — это ключевой ход:
    y′ = ex+13·(2x − 11 + x² − 11x + 11) = ex+13·(x² − 9x)
  5. Раскладываем: x² − 9x = x(x − 9). Экспонента всегда > 0 → знак задаёт только скобка.
  6. Корни 0 и 9. Знаки: + − +. Точка минимума — 9.
Готовая формула для этого прототипа. Для y = P(x)·ex+b скобка всегда = P′ + P. Для y = P(x)·eb−x скобка = P′ − P. Проверь на задаче выше: (2x−11) + (x²−11x+11) = x² − 9x. Пятнадцать секунд вместо трёх минут.

➗ Правило 3. Частное — следи за порядком

(u/v)′ = (u′·v − u·v′) / v²
Ловушка формулы. В числителе стоит минус, а значит порядок слагаемых менять нельзя. u′v − uv′ и uv′ − u′v отличаются знаком, то есть максимум превратится в минимум. Мнемоника: «сначала штрих сверху, потом минус».
Простой пример — проверка формулы

Возьмём y = 1/x. Мы знаем ответ: y′ = −1/x².
По формуле: u = 1, u′ = 0; v = x, v′ = 1 → y′ = (0·x − 1·1)/x² = −1/x² ✔

Пример из ЕГЭ — дробная крепость

Найдите точку минимума y = − x/(x² + 256)

  1. Минус выносим вперёд и пока не трогаем: y = −(x/(x²+256)).
  2. u = x, u′ = 1; v = x² + 256, v′ = 2x.
  3. (x/(x²+256))′ = (1·(x²+256) − x·2x)/(x²+256)² = (256 − x²)/(x²+256)²
  4. С учётом внешнего минуса: y′ = (x² − 256)/(x² + 256)²
  5. Знаменатель — квадрат, он всегда > 0. Знак задаёт числитель x² − 256 = (x − 16)(x + 16).
  6. Знаки + − + → минимум в большем корне: 16.
Лайфхак: формула частного часто не нужна. Если в знаменателе одинокий x — просто раздели почленно.
y = −(x² + 361)/x = −x − 361/x → y′ = −1 + 361/x². Никакой громоздкой дроби.

🪆 Правило 4. Сложная функция — матрёшка

Сложная функция — это когда внутри одной функции сидит другая. Не «x под логарифмом», а целое выражение под логарифмом. Правило: производная внешней (внутренность не трогаем) × производная внутренней.

(f(g(x)))′ = f′(g(x)) · g′(x)

А вот здесь множитель уже видно — и именно он ломает половине выпускников знаки:

ФункцияВнешняя даётНачинка даётИтог
ln(x + 8)1/(x+8)(x+8)′ = 11/(x+8)
ln(4 − x)1/(4−x)(4−x)′ = −1−1/(4−x)
ex+13ex+13(x+13)′ = 1ex+13
e3−xe3−x(3−x)′ = −1−e3−x
(x + 5)²2(x+5)(x+5)′ = 12(x+5)
√(2x + 1)1/(2√(2x+1))(2x+1)′ = 21/√(2x+1)
sin 3xcos 3x(3x)′ = 33·cos 3x
Простой пример

y = (2x + 1)³. Внешняя — куб: даёт 3(2x+1)². Внутренняя 2x+1 даёт 2.
Ответ: y′ = 3(2x+1)²·2 = 6(2x+1)².
Проверка: раскрой скобки и продифференцируй почленно — получишь то же самое, только за пять минут вместо десяти секунд.

Пример из ЕГЭ — тройная матрёшка

Найдите точку максимума y = (x + 8)²·e3−x

  1. Здесь произведение, а внутри каждого множителя ещё и сложная функция. Разбираем по слоям.
  2. u = (x+8)² → сложная: u′ = 2(x+8)·1 = 2(x+8).
  3. v = e3−x → сложная: v′ = e3−x·(−1) = −e3−x. Вот он, минус.
  4. Правило произведения: y′ = 2(x+8)·e3−x + (x+8)²·(−e3−x)
  5. Выносим e3−x(x+8) — общий множитель:
    y′ = e3−x·(x+8)·(2 − (x+8)) = e3−x·(x+8)·(−x−6)
  6. Или красивее: y′ = −e3−x·(x+8)(x+6). Корни: −8 и −6.
  7. Минус перед всем выражением переворачивает знаки: вместо + − + получаем − + −. Значит в −6 идёт смена «+ → −» → максимум = −6.
Проверь себя. Если бы в показателе стояло ex+3, минуса бы не было, знаки шли бы + − +, и точка −6 оказалась бы минимумом. Одна лишняя закорючка в показателе — противоположный ответ.

Последний пример: произведение, где всё сокращается

Найдите точку максимума y = (5x − 1)·cos x − 5·sin x + 17 на (0; π/2)

  1. Первое слагаемое — произведение: u = 5x − 1 (u′ = 5), v = cos x (v′ = −sin x).
  2. ((5x−1)·cos x)′ = 5·cos x + (5x−1)·(−sin x) = 5cos x − (5x−1)·sin x
  3. (−5 sin x)′ = −5 cos x, (17)′ = 0.
  4. Складываем: y′ = 5cos x − (5x−1)sin x − 5cos x = −(5x − 1)·sin x. Косинусы взаимно уничтожились.
  5. На промежутке (0; π/2) синус положителен, поэтому знак решает только скобка: при x < 0,2 скобка отрицательна → y′ > 0; при x > 0,2 → y′ < 0.
  6. Смена «+ → −» → точка максимума 0,2.

Знаковая прямая: алгоритм «ЗНАКИ»

Пять шагов. Первые буквы — снова слово. Работает на любой производной задания 12.

📏 Второе слово-ключ

ЗНАКИ
З
Заводи производную в вид «произведение / дробь»Разложи на множители: x² − 9x → x(x − 9). Пока стоит сумма — знаки не читаются.
Н
Наноси на прямую все особые точкиКорни числителя (закрашенные ●) и точки, где функция не существует: нули знаменателя, границы ОДЗ (выколотые ○).
А
Анализируй самый правый промежутокПодставь большое число (например 1000) или посмотри на старший коэффициент. Обычно там «+».
К
Кочуй влево, чередуя знакиЧерез простой корень знак меняется. Через корень в чётной степени — не меняется. Через выколотую точку — смотри, что там в знаменателе.
И
Итог: читай смену знака«− → +» = минимум. «+ → −» = максимум. Знак не сменился = экстремума нет, это просто перегиб.

🐷 Как это выглядит: разбор по шагам

Быстрый способ вместо подстановки. Если производная — многочлен с положительным старшим коэффициентом, справа всегда «+». Дальше просто чередуй влево. Подставлять 1000 нужно только когда есть минус впереди или непонятный множитель.

⚠️ Четыре случая, когда чередование ломается

1. Минус перед всем выражением

y′ = −(x + 8)(x + 6). Справа поставили «+», получили + − + и назвали −6 минимумом.
Подставляем x = 1000: −(1008)(1006) < 0 → справа минус. Схема − + −, и −6 — максимум.

Так устроены все задачи с eb−x: минус приезжает из производной начинки.

2. Корень в чётной степени — знак не меняется

y′ = (x − 1)²(x − 4). Отметили корни 1 и 4, честно чередовали: − + −... и объявили x = 1 точкой максимума.
Квадрат (x−1)² неотрицателен всегда — он не может поменять знак. Схема на самом деле − − +. В точке 1 экстремума нет, минимум только в 4.

Правило: чётная степень корня — «отскок», знак сохраняется. Нечётная — «прокол», знак меняется.

3. Точка разрыва — знак может меняться без корня

y′ = (x² − 196)/x². Отметили только ±14 и решили, что в нуле ничего не происходит... а знаменатель-то обнуляется.
Ноль ставим на прямую как выколотую точку. Здесь знаменатель x² — чётная степень, знак через 0 не меняется, схема + − − +. Максимум −14, минимум 14.

Выколотая точка никогда не бывает ответом — функции там просто нет. Но на схему её наносить обязательно.

4. Граница ОДЗ обрезает прямую

y′ = (2x² + 3x − 44)/x для y = x² + 3x − 44 ln x. Нашли корни 4 и −5,5, нарисовали три промежутка, взяли −5,5 как максимум.
У ln x область x > 0. Прямая начинается в нуле, всё левее не существует. Остаётся один корень: 4, знаки − + → минимум 4.

ОДЗ рисуется на прямой первым. Тогда «лишние» корни отваливаются сами.

Типичные ошибки

Восемь ловушек, на которых теряют балл при полностью верном ходе решения.

№1 Ответили точку вместо значения

Найдите наименьшее значение y = x√x − 9x + 23 на [1; 49].
Нашли √x = 6, x = 36. Записали 36.
x = 36 — это только адрес. Подставляем: y(36) = 216 − 324 + 23 = −85.
Шаг П алгоритма ПТИЦА существует ровно ради этого. Спросили «значение» — обязан подставить.

№2 Забыли про ОДЗ логарифма

y = x² + 3x − 44·ln x − 97. Числитель 2x² + 3x − 44, корни 4 и −5,5. Взяли −5,5 как максимум.
У ln x область x > 0. Корень −5,5 не существует. Остаётся x = 4 — минимум.
Шаг Т. Территория пишется до дифференцирования, иначе мусорные корни просятся в бланк.

№3 Не посчитали концы отрезка

y = x³ − 6x² + 9x + 5 на [0; 3]. Нашли максимум в x = 1, y(1) = 9. Записали 9 и ушли — а могло не повезти.
Считаем всё: y(0) = 5, y(1) = 9, y(3) = 5. Максимум действительно 9 — но узнали мы это только сравнив три числа.
На отрезке наибольшее значение может сидеть на конце. Формула проверки: (корни внутри) + левый конец + правый конец.

№4 Не свернули степень логарифма

y = 9x − ln(x + 4)⁹. Полезли дифференцировать степень через сложную функцию, потеряли 4 минуты и знак.
Сначала свойство: ln(x+4)⁹ = 9·ln(x+4). Тогда y′ = 9 − 9/(x+4) = 0 → x = −3, y(−3) = −27.
Шаг И начинается со слова «упрости». ln(9x) = ln9 + ln x, −(x²+361)/x = −x − 361/x.

№5 Перепутали правило произведения

y = (7 − x)·e7−x. Посчитали как u′·v′ = (−1)·(−e7−x) = e7−x. Корней нет, задача «не решается».
y′ = (−1)·e7−x + (7−x)·(−e7−x) = e7−x·(−1 − 7 + x) = e7−x(x − 8) → минимум 8.
Производная произведения — это не произведение производных. Проверь на x²·x³: должно выйти 5x⁴, а «u′v′» даёт 6x³.

№6 Проглядели минус в показателе экспоненты

y = (x + 8)²·e3−x. Скобку собрали как P′ + P, знаки взяли + − + и назвали x = −6 минимумом.
Начинка 3 − x даёт множитель −1. Скобка = P′ − P, перед всем выражением минус, схема − + − → x = −6 это максимум.
Сложная функция + знаковая прямая в одном флаконе. ex+b → скобка P′ + P. eb−x → скобка P′ − P.

№7 Искали корни там, где их нет

y = 56 cos x + 59x + 42 на [0; 3π/2]. Решали sin x = 59/56, получили ерунду, бросили задачу.
59/56 > 1 — синус столько не умеет. Корней нет → y′ > 0 всегда → функция растёт → минимум на левом конце: y(0) = 56 + 42 = 98.
«Уравнение не решается» — это не тупик, а подарок: функция монотонна, ответ на конце отрезка.

№8 Забыли возвести корень в квадрат

y = x3/2 − 21x + 11. Получили 1,5·√x = 21 → √x = 14. Записали 14.
Спрашивали x, а не √x. Возводим: x = 14² = 196.
В этом прототипе ответ почти всегда точный квадрат: 4, 16, 36, 144, 196, 256. Получил 14 — остановился на шаг раньше.
