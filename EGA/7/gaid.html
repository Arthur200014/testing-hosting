🧅 Главный принцип: у выражений есть слои

Не грызи выражение целиком. Снимай по слою: внутренняя скобка → упрощение → следующий слой. И держи железное правило: сначала упрощаем буквами, числа подставляем последними. Подставил рано — получил кашу из десятичных дробей и потерял 1 балл на ровном месте.

🌊 Корни

√a·√b = √(ab) √a√b = √(a/b) (√a)² = a √(a²) = |a| √(a²b) = |a|√b n√(am) = am/n
🌊
Корень — болотная жижа: два числа под одним корнем можно смешать, а сумму разлить нельзя. √(9+16)=5, а не 3+4=7.

Сопряжённое — главный приём против дроби с корнем:

(√a−√b)(√a+√b) = a − b

6√5−√2 = 6(√5+√2)5−2 = 2(√5+√2). Умножаем верх и низ на «зеркального близнеца» — корни внизу умирают.

🔎 Логарифмы

logₐb = c ⇔ ac = b logₐ(xy) = logₐx + logₐy logₐxy = logₐx − logₐy logₐ(xp) = p·logₐx log(aᵏ)x = 1klogₐx alogₐb = b logₐa = 1 logₐ1 = 0 logₐb = logcblogca
🔎
Логарифм — стражник, который спрашивает: «в какую степень возвести a, чтобы вышло b?». log₂8 = 3, потому что 2³ = 8. lg = log₁₀, ln = loge.

Тактика: все log с одинаковым основанием собери в один (сумма→произведение, разность→частное), потом посчитай по определению. Разные основания — переведи через формулу перехода.

🍰 Рациональные и ФСУ

a²−b² = (a−b)(a+b) (a±b)² = a²±2ab+b² a³±b³ = (a±b)(a²∓ab+b²) ax²+bx+c = a(x−x₁)(x−x₂)
🍰
Вафельный домик строят по кирпичику: разложи → сократи → подставь. Порядок нарушил — домик развалился.

Пример: x²−49x+7 при x=13  →  (x−7)(x+7)x+7 = x−7 = 6. Считать 13²−49=120 и делить на 20 — тоже можно, но это лишний шанс ошибиться.

Правило коня (формулы приведения): угол через π (180°) — конь мотает головой «нет», функция не меняется (sin остаётся sin). Угол через π/2 (90°) — конь кивает «да», функция меняется (sin↔cos). Знак ставим по четверти исходной функции. Пример: sin(π−α)=sin α, cos(π/2+α)=−sin α.

стр. 3

Розыск: ловушки

эти твари живут во всех прототипах
❌ как ошибаются · ✅ как надо

Каждое объявление — реальная ошибка, за которую в задании 7 снимают весь балл. Балл тут один. Второго шанса нет.

РАЗЫСКИВАЕТСЯ❌ 1. Разлил логарифм по сумме log₂(8+8) = log₂8 + log₂8 = 6 ✅ Так нельзя! Сумму сначала посчитай внутри: log₂16 = 4. Правило про сумму работает наоборот: logₐx+logₐy = logₐ(xy).
РАЗЫСКИВАЕТСЯ❌ 2. Разлил корень по сумме √(9+16) = 3 + 4 = 7 ✅ √(9+16) = √25 = 5. Корень дружит только с умножением и делением, не со сложением.
РАЗЫСКИВАЕТСЯ❌ 3. Забыл про удвоенное произведение (a+b)² = a² + b² ✅ (a+b)² = a² + 2ab + b². Особенно больно с корнями: (√3+1)² = 3+2√3+1 = 4+2√3.
РАЗЫСКИВАЕТСЯ❌ 4. √(a²) = a √((−6)²) = −6 ✅ √(a²) = |a|, результат корня всегда ≥ 0. √((−6)²) = 6. И √(x²)·√(x²) — тоже сначала модули.
РАЗЫСКИВАЕТСЯ❌ 5. Перепутал × и ^ у степеней 2³·2⁵ = 2¹⁵  или  (2³)⁵ = 2⁸ ✅ Умножаем — складываем: 2³·2⁵ = 2⁸. Степень в степени — умножаем: (2³)⁵ = 2¹⁵. Ровно наоборот тому, что просится.
РАЗЫСКИВАЕТСЯ❌ 6. Подставил числа слишком рано (x²−49)/(x+7) при x=13 → 169−49=120, 120/20 = 6… а если бы числа были злее — каша и потеря времени. ✅ Сначала сократи: (x−7)(x+7)/(x+7) = x−7 = 6. Меньше действий — меньше шансов промазать.
РАЗЫСКИВАЕТСЯ❌ 7. Потерял 1/k у основания-степени log₉27 = 3 (мол, «27 = 3³») ✅ 9 = 3², значит log₉27 = ½·log₃27 = 1,5. Основание — тоже степень, коэффициент не забываем.
РАЗЫСКИВАЕТСЯ❌ 8. Перепутал tg и ctg tg α = cos α / sin α ✅ tg = sin/cos (синус сверху — «с» первая в алфавите). ctg = cos/sin. Перевёрнутая дробь — минус балл.
РАЗЫСКИВАЕТСЯ❌ 9. Формулы приведения наугад cos(π/2 + α) = cos α  или  sin(π − α) = −sin α ✅ Через π/2 функция меняется: cos(π/2+α) = −sin α. Через π не меняется: sin(π−α) = sin α. Знак — по четверти исходной функции.
РАЗЫСКИВАЕТСЯ❌ 10. Не тот cos 2α cos 2α = 2 cos α  или  1 − 2cos²α ✅ cos 2α = 1 − 2sin²α = 2cos²α − 1 = cos²α − sin²α. Выбирай ту версию, где стоит известная тебе функция.
РАЗЫСКИВАЕТСЯ❌ 11. Дробь с корнем оставил как есть 6/(√5−√2) — «дальше не упрощается». ✅ Умножь верх и низ на сопряжённое (√5+√2): внизу станет 5−2=3, и всё посчитается.
РАЗЫСКИВАЕТСЯ❌ 12. Ответ не в том формате Записал 5/2, √4, «6 см» или 6.5 с точкой. ✅ 2,5 · 2 · 6 · 6,5. Только число, только десятичная дробь через запятую, без единиц.
